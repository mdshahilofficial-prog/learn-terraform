Interview rapid-fire

Why remote state?

Centralized state, collaboration, locking where supported, and durable storage. In production, protect the backend with access controls, encryption and versioning.

Why lock state?

To prevent concurrent operations from writing conflicting state changes. Locking is a backend capability, not a universal property of every storage mechanism.

What is drift?

Actual infrastructure differs from what Terraform state/configuration expects. Plan can expose drift; remediation depends on whether code or infrastructure should win.

Why .terraform.lock.hcl?

It records selected provider package versions/checksums so different machines and CI systems can install consistent provider packages.

Why modules?

To package reusable infrastructure patterns, standardize interfaces, reduce duplication and enforce conventions.

Why not hard-code secrets?

Terraform state can contain sensitive values. Use secret-management systems and secure backend access; marking a variable sensitive only hides display, it does not encrypt state by itself.
